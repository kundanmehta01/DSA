# Prefix Sum — DSA Pattern

Prefix Sum is used when a problem asks about the **sum of elements in a range** repeatedly.

Example:

```text
nums = [2, 4, 1, 7, 3]
```

Suppose we want:

```text
sum from index 1 to 3
= 4 + 1 + 7
= 12
```

Instead of calculating the sum every time, we **precompute cumulative sums**.

---

## 1. What is Prefix Sum?

A prefix sum array stores the sum of all elements **before a position**.

For:

```text
nums = [2, 4, 1, 7, 3]
```

We create:

```text
prefix = [0, 2, 6, 7, 14, 17]
```

Let's understand it:

| Index | Meaning | Value |
|---|---|---:|
| `prefix[0]` | nothing | 0 |
| `prefix[1]` | `2` | 2 |
| `prefix[2]` | `2 + 4` | 6 |
| `prefix[3]` | `2 + 4 + 1` | 7 |
| `prefix[4]` | `2 + 4 + 1 + 7` | 14 |
| `prefix[5]` | all elements | 17 |

### Formula

```python
prefix[i + 1] = prefix[i] + nums[i]
```

---

# 2. The Main Formula ⭐

To find the sum from index `left` to `right`:

```python
range_sum = prefix[right + 1] - prefix[left]
```

### Example

```text
nums = [2, 4, 1, 7, 3]

Find sum from index 1 to 3

[2, 4, 1, 7, 3]
    ↑        ↑
   left     right
```

Using prefix:

```text
prefix[right + 1] - prefix[left]

prefix[4] - prefix[1]

14 - 2 = 12
```

Why?

```text
prefix[4] = 2 + 4 + 1 + 7
prefix[1] = 2

Subtract:

(2 + 4 + 1 + 7) - 2

= 4 + 1 + 7
= 12
```

---

# 3. Why do we put `0` at the beginning?

This is very important.

We use:

```python
prefix = [0]
```

Then:

```python
for num in nums:
    prefix.append(prefix[-1] + num)
```

For:

```python
nums = [2, 4, 1]
```

Result:

```text
prefix = [0, 2, 6, 7]
```

This makes the formula always simple:

```python
sum(left, right) = prefix[right + 1] - prefix[left]
```

Without special cases like:

```python
if left == 0:
```

So remember:

> **`prefix[i]` = sum of the first `i` elements.**

Not the sum *up to index i*.

---

# 4. Basic Code

```python
nums = [2, 4, 1, 7, 3]

prefix = [0]

for num in nums:
    prefix.append(prefix[-1] + num)

print(prefix)
```

Output:

```text
[0, 2, 6, 7, 14, 17]
```

Now:

```python
left = 1
right = 3

answer = prefix[right + 1] - prefix[left]

print(answer)
```

```text
12
```

# 5. Time Complexity

Suppose you have many queries:

```text
What is sum from 2 to 5?
What is sum from 1 to 4?
What is sum from 0 to 7?
```

### Without Prefix Sum

Every query may take:

```text
O(n)
```

For `q` queries:

```text
O(n × q)
```

### With Prefix Sum

Build prefix:

```text
O(n)
```

Each query:

```text
O(1)
```

Total:

```text
O(n + q)
```

This is the main benefit.

# 7. Important Variation: Prefix Sum + HashMap 🔥

This is one of the most important Prefix Sum patterns.

Problem:

> Count subarrays whose sum equals `k`.

Example:

```text
nums = [1, 2, 3]
k = 3
```

Valid subarrays:

```text
[1, 2] → 3
[3]    → 3
```

Answer:

```text
2
```

---

## The idea

Suppose current prefix sum is:

```text
current_sum
```

We want a previous prefix sum such that:

```text
current_sum - previous_sum = k
```

Therefore:

```text
previous_sum = current_sum - k
```

So at every position:

```python
if current_sum - k exists in hashmap:
    we found subarray(s)
```

### Code

```python
def subarraySum(nums, k):
    count = 0
    prefix_sum = 0

    freq = {0: 1}

    for num in nums:
        prefix_sum += num

        if prefix_sum - k in freq:
            count += freq[prefix_sum - k]

        freq[prefix_sum] = freq.get(prefix_sum, 0) + 1

    return count
```

This pattern is extremely important:

```text
Prefix Sum + HashMap
```

You already learned `HashMap`, so this will connect nicely.

# Prefix Sum Patterns You Should Learn

### Level 1 — Basic Range Sum

```text
Prefix Sum Array
```

Formula:

```python
prefix[right + 1] - prefix[left]
```

---

### Level 2 — Prefix Sum + HashMap

For problems like:

```text
Subarray sum equals K
```

Pattern:

```python
prefix_sum += num

need = prefix_sum - k

if need in hashmap:
    answer += hashmap[need]

hashmap[prefix_sum] += 1
```

---

### Level 3 — Prefix Sum with Modulo

Problems like:

```text
Subarray sum divisible by K
```

Pattern:

```python
prefix_sum % k
```

Use a HashMap to store frequencies of remainders.

---

### Level 4 — 2D Prefix Sum

For matrices:

```text
Find sum inside a rectangle
```

Example:

```text
matrix

1 2 3
4 5 6
7 8 9
```

We will study this after you become comfortable with 1D Prefix Sum.

## The one-line intuition to remember

> **Prefix Sum converts a subarray problem into a relationship between two prefix sums.**

For now, master these **two core ideas**:

```text
1. Range Sum
prefix[right + 1] - prefix[left]

2. Subarray Sum = K
current_prefix - previous_prefix = k

Therefore:

previous_prefix = current_prefix - k
```

The next best step is to do **Range Sum Query → Pivot Index → Subarray Sum Equals K**, because that gradually builds from basic Prefix Sum to the important **Prefix Sum + HashMap** pattern.
