Kadane's Algorithm
1. What is it?

Find the maximum sum contiguous subarray in O(n).

Instead of checking every subarray (O(n²)), keep only the best running sum.

Idea

If current sum becomes negative, discard it because it can only reduce the sum of future subarrays.

current += num

if current < 0:
    current = 0
Template
current = 0
best = float('-inf')

for num in nums:
    current += num
    best = max(best, current)

    if current < 0:
        current = 0

return best
Dry Run
nums = [-2,1,-3,4,-1,2,1,-5,4]

current: 0
best: -inf

-2 → current=-2 → best=-2 → reset=0
1  → current=1  → best=1
-3 → current=-2 → reset=0
4  → current=4  → best=4
-1 → current=3
2  → current=5  → best=5
1  → current=6  → best=6
-5 → current=1
4  → current=5

Answer = 6

Subarray:

[4, -1, 2, 1]
When to Apply

Think Kadane when you see:

✅ Maximum subarray sum

✅ Contiguous subarray

✅ Largest profit/score over consecutive elements

✅ O(n) solution expected
